# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 3.x     | Yes       |
| < 3.0   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in **Cupcake Box**, please do **not** open a public issue. Instead, report it privately via GitHub Security Advisories on this repository or reach out through [alfareza.site](https://alfareza.site).

Please include:
- A clear description of the vulnerability and affected component(s)
- Steps or a minimal Proof of Concept (PoC) to reproduce the issue
- Potential impact and suggested remediation (if available)

> **Note:** Permissions that grant server creation, environment configuration, or template editing (`admin`, `server.create`, `templates.local.edit`) are administrative scopes by design.
